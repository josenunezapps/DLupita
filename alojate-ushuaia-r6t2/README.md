# Alojate Ushuaia (demo)

Demo navegable de plataforma de alquileres temporarios en Ushuaia: búsqueda con filtros, ficha con reseñas verificadas, reserva con seña del 30% (pago simulado), formulario de reseña y panel del dueño (reservas, calendario, comisión).

Datos ficticios, todo en memoria (se reinicia al recargar). Un solo archivo HTML, sin dependencias.

Publicada en: https://josenunezapps.github.io/DLupita/alojate-ushuaia-r6t2/
