Acerca de la app

FilaCero v0.1 es una demostración comercial de Zenix AR. El turnero reinicia su numeración cada día según el reloj de este dispositivo.

La versión demostrativa no sincroniza equipos distintos, no identifica clientes, no es apta para turnos médicos reales ni garantiza consistencia si dos operadores emiten o llaman turnos al mismo tiempo. Para un negocio real se requiere un servidor y una base de datos compartida.
