# Zenix AR · Apps para comercios (landing)

Página de presentación con simulación de fluidos en la GPU (Navier–Stokes en WebGL, escrita a mano) que reacciona al mouse o al dedo, y un teléfono que muestra las apps **funcionando en vivo** a medida que bajás: Zenix Caja, Cotiza, Club y Escáner. En celular cada app se carga al tocar, para ahorrar datos. Incluye Neurona y Órbita Austral como experiencias, y CTA a WhatsApp.

**Ver:** https://josenunezapps.github.io/DLupita/zenix-apps/
